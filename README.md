# EternalRPG

A C++17 truecolor terminal RPG inspired by the supplied ASCII game recordings.

```sh
cmake -B build
cmake --build build
./build/eternal_rpg
```

Use a truecolor terminal and a monospace font; 200 columns × 60 rows recommended. `Q` exits. `--headless --frames 120 --dump frame.json` captures the framebuffer. See the [milestone log](docs/MILESTONES.md).
